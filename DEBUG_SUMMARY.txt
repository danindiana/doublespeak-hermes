TECHNICAL DETAILS
================================================================================

Issue Analysis:
- Torch and Ollama initialization overlap in module load time
- Both libraries initialize GPU/compute resources during import
- This caused blocking in the wrapper module's __init__ context

API Response Objects:
- ollama.ListResponse: Has `.models` attribute (list of Model objects)
- Model object: Has `.model` attribute (model name string)
- ollama.GenerateResponse: Has `.response` attribute (generated text)

Fixed Implementation:
- Direct API usage avoids wrapper initialization issues
- Proper attribute access for response objects
- Lazy connection (connect on first use, not at import)
