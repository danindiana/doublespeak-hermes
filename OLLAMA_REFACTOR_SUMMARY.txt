=== USAGE ===

Basic usage:
    python example_usage.py

With custom parameters:
    python example_usage.py \
        --model-name hermes3:8b \
        --harmful-keyword "bomb" \
        --benign-substitute "carrot" \
        --num-examples 10 \
        --output-dir outputs
